{{/* pagination — a numbered page strip of ordinary links, so paging works with JavaScript disabled. The current page carries aria-current="page" as well as a filled chip and a heavier weight: three signals, never colour alone. Keys: Items slice, optional — one entry per control. Each has: Label string — the visible text ("1", "Next") Href string — where it goes Current bool — this is the page being viewed Disabled bool — present but not actionable Gap bool — the "…" between page ranges Exactly one of Href / Current / Disabled / Gap is meaningful per item. Label string, optional — the
's accessible name, default "Pagination". This package wires no localization catalog, so an app with one passes its own string. */}} {{define "pagination"}}
{{- if .Items}}{{range .Items}} {{- if .Gap}}… {{- else if .Current}}{{.Label}} {{- else if .Disabled}}{{.Label}} {{- else}}{{.Label}} {{- end}} {{- end}}{{end}}
{{end}}
